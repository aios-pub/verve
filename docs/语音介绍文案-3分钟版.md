大家好，今天给大家介绍一款名为 Verve 的 API 协作开发平台。

作为一名后端开发者，我想大家都有过这样的经历：调试 API 的时候，需要在好几个工具之间来回切换。用 Postman 发送请求，发现接口报错了，赶紧切到终端 SSH 上服务器查看日志；找到问题后，回到 Postman 修改参数再试；前端同事问接口文档，又要打开 Swagger 生成文档。这样一番操作下来，半小时的调试工作，大半时间都花在了工具切换上。

而且大家有没有发现，现在很多开发工具都是用 Electron 开发的，就是那个打包了整个 Chrome 内核的技术框架。这些应用启动要好几秒，内存占用动不动就500兆以上，用久了还会卡顿，体验确实不够理想。

这就是为什么我想给大家介绍 Verve 的原因。

Verve 是一款用 Rust 语言编写的桌面应用，它最核心的特点就是"一体化集成"。在一个工具里，同时提供了 API 调试、SSH 终端、文档分享和 Git 版本控制这四大功能。

具体来说，你在 Verve 里调试 API 时，左边是请求面板，右边就是 SSH 终端。调试遇到问题，直接在右侧查看服务器日志，不需要切换到其他应用。文档生成也很简单，右键点击项目就能生成精美的 HTML 文档，支持二维码分享、链接分享，还能设置过期时间和密码保护。

说到这里，我想重点强调一下 Verve 的技术亮点。它是用 GPUI 框架开发的，GPUI 可能很多朋友没听说过，它是 Zed 编辑器使用的 UI 框架。Zed 是号称"性能最好的代码编辑器"，GPUI 就是它的核心技术。Verve 应该是少数采用 GPUI 的生产级应用之一。

因为用的是原生开发，不是 Electron 那种套壳的方式，Verve 的性能表现非常出色。内存占用不到100兆，启动速度不到1秒，响应速度是毫秒级的。相比之下，那些 Electron 应用通常要500兆以上内存，启动好几秒，体验差距还是很明显的。

功能方面，HTTP 调试支持所有常用的请求方法，各种请求体类型都支持，还有智能变量替换和脚本功能。SSH 终端支持多标签页，可以同时管理多台服务器，支持自动重连和堡垒机跳板。文档分享功能可以生成漂亮的 HTML 页面，访问控制也很完善。Git 版本控制支持多工作区，可以自动提交和同步，团队协作很方便。

Verve 支持 Mac、Windows 和 Linux 全平台。https://github.com/aios-rs/verve 如果想要官方版本和优先技术支持，也可以捐赠99元获取授权。

总的来说，如果你受够了多工具切换的繁琐，或者想找一个真正流畅的 API 开发工具，Verve 绝对值得一试。一个工具搞定 API 调试、服务器管理、文档分享和版本控制，而且性能这么好，用了就回不去了。

欢迎大家给Verve个star。谢谢大家。
