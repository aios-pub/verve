## 💡 2分钟深度介绍

大家好，今天给大家详细介绍一款名为 Verve 的 API 协作开发工具。

### 开发痛点

做后端开发的都知道，调试 API 是个繁琐的过程。用 Postman 发请求，出了问题要切到终端 SSH 上服务器看日志，要写文档又要打开 Swagger，要管理版本还得用 Git。这些工具之间来回切换，很容易打断思路。

### 一体化解决方案

Verve 的做法是把所有这些功能集成到一个桌面应用里。左边是 API 调试面板，右边是 SSH 终端，调试过程中发现问题，直接在右边查看服务器状态，不需要切应用。

它还支持一键生成 API 文档，可以生成二维码、链接或者导出 HTML 文件。文档分享支持过期时间和密码保护，适合团队协作。

### 技术亮点

Verve 最特别的地方是，它用 Rust 语言和 GPUI 框架开发。GPUI 是什么？它是 Zed 编辑器使用的 UI 框架，专门为高性能应用设计的。

因为用原生开发，Verve 的内存占用不到 100 兆，启动速度不到 1 秒，响应速度是毫秒级的。相比之下，那些用 Electron 开发的工具，内存要 500 兆以上，启动要好几秒。

### 功能特性

具体功能方面，Verve 支持所有 HTTP 方法，支持各种请求体类型，有智能变量替换和脚本支持。SSH 终端支持多标签、自动重连、堡垒机跳板。文档分享可以生成精美的 HTML，访问控制很完善。Git 版本控制支持多工作区，自动提交和同步。

### 开源免费

Verve 是完全开源的，使用 MIT 许可证，支持 Mac、Windows 和 Linux。开发者也可以捐赠 99 元获取官方版本，包括持续更新和优先技术支持。

总的来说，如果你受够了多工具切换，或者想找一个真正流畅的 API 开发工具，Verve 值得一试。

## 🔧 技术向介绍（1分钟）

大家好，今天从技术角度介绍一款名为 Verve 的工具。

### 技术栈

Verve 使用 Rust 语言开发，UI 框架选用了 GPUI。GPUI 可能很多人没听说过，它是 Zed 编辑器使用的框架，专门为高性能应用设计，基于 GPU 渲染，能稳定保持 60 帧率。

Verve 应该是少数采用 GPUI 的生产级应用之一。这意味着它继承了 Zed 的性能优势，响应速度是毫秒级的。

### 技术优势

相比 Electron 应用，Verve 的优势很明显：内存占用不到 100 兆，启动速度不到 1 秒，包体积小于 50 兆。而 Electron 应用通常内存要 500 兆以上，启动要好几秒，包体积 200 兆起步。

### 架构设计

功能架构上，Verve 集成了四个核心模块：HTTP 调试基于原生 HTTP 客户端，SSH 终端使用 russh 库，文档分享内置了 HTTP 服务器，Git 版本控制使用 gitoxide。

因为都是 Rust 生态的原生库，整个应用非常统一，没有跨语言调用的开销。

### 开源贡献

Verve 完全开源，采用 MIT 许可证。对于想学习 Rust + GPUI 开发的开发者，也是一个很好的参考项目。
